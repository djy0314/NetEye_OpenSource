NetEye 网络透视镜 v0.9.3
========================================

v0.9.3 更新记录
---------------
1. 进程图标：「进程名」左侧新增 16x16 程序图标，按 exe 路径缓存、后台线程提取，
   几十个同名进程只提取一次；受保护进程画兜底占位图，绝不卡顿、绝不报错。
2. 搜索增强：搜索框右侧新增「包含 / 精确 / 正则」下拉。包含 = 原来的子串匹配；
   精确 = 词必须完整等于协议/端点/状态/PID/进程名之一；正则 = 整个输入作为一条
   忽略大小写的正则对整行摘要匹配，写错正则时提示并显示全部行。
3. 表格密度：右键菜单「紧凑行高」在宽松（22px）/紧凑（18px）两档切换，
   高分屏一眼能看更多行；选择写入 config.ini，下次打开保持不变。
4. 列宽记忆：拖动列宽自动按「逻辑像素」写入 config.ini（换 DPI 等比还原），
   下次打开原样恢复；进程名列是弹性 Fill 列，不参与记忆。
5. 网速曲线：鼠标悬停状态栏网速「↑ ↓」弹出实时折线小图（下行绿线 / 上行蓝线，
   纵轴按峰值自适应，最近 120 秒），移开自动消失。
6. 防火墙拦截：右键「防火墙拦截此程序出站…」一键创建 Windows 防火墙出站
   阻止规则（netsh advfirewall，需管理员身份运行），深色确认框列明程序与
   路径；撤销在 wf.msc 出站规则里删掉名称以 [NetEye] 开头的规则即可。
7. 反查域名：右键「反查远程 IP 域名」用系统 DNS 反向解析（PTR）拿主机名，
   内网 IP 也能反查设备名；解析放后台线程，超时/失败只提示「没有解析到」，
   工具本体依旧不联网。
8. 记录模式：右键「记录新连接」开启后，每次刷新把新出现的连接追加写入
   logs\NetEye_连接_年月日.csv（带时间戳），排查闪断/短连接流氓软件利器；
   开启瞬间已有的连接也会记一次作为基线，关闭恢复原样，配置同样持久化。
9. 离线库更新器：⚙ 设置里新增「更新离线库」，纯 C# 内置下载，不依赖任何外部脚本
   （不调 PowerShell，企业机把 ExecutionPolicy 设成 AllSigned/Restricted 也拦不到它）。
   4 个开源镜像顺序自动切换（ghfast / gh-proxy / gitmirror / GitHub raw）：建连或
   响应头 10 秒没动静就换下一个，传输中途 20 秒收不到数据也换源。
   · 三重校验：体积必须 > 1MB；头 8 字节解析索引区首/末偏移（first ≥ 8、
     last < 文件长度、(last-first) 能被 7 整除）；再抽第一条索引读 3 字节记录偏移，
     必须落在文件内（防「头部对、内容空」的假库）。
   · 安全覆盖：先写 qqwry.dat.part → 校验通过 → 旧库备份成 qqwry.dat.bak →
     原子替换成 qqwry.dat；任何一步失败都不动现有旧库，绝不留半个文件。
   · 下载前先探写入权限：装在 Program Files 这类目录会立刻提示「当前目录无写入
     权限，请将软件放到其他目录重试」，不会让你白等 25MB。
   · 进度可见：按钮变灰实时显示「下载中 37%…」，完成后弹「离线库更新成功」并
     立即生效（不用重启）；下载中关掉设置窗不中断，关主程序则取消并清掉 .part。
10. 导出 JSON：导出对话框新增 JSON 格式（UTF-8 无 BOM，字段 protocol/local/
    remote/state/pid/process/uptime/kind），给自动化脚本消费；CSV 保持不变，
    自动存档恒为 CSV。没有加 Excel(.xlsx) 导出 —— CSV 本身就是 Excel 标准入口，
    真做 xlsx 要引 OOXML 压缩库，违背「纯单文件、零依赖」。

v0.9.2 更新记录
---------------
1. 新增「运行时长」列（对标 CurrPorts 的 Created 列）：显示占用这条连接的进程已经
   跑了多久，格式 45s / 2m 05s / 2h 15m / 3d 04h；点表头能按长短排序。
   读不到启动时间的进程（System、Idle、受保护进程）统一显示「-」，

   只留右边 1/3/5 秒的频率下拉。省出来的位置给了「⚙ 设置」。
3. 设置面板内嵌：点顶部「⚙ 设置」弹出深色小窗，直接改「自定义查询 IP 的网址」，
   点保存就写回 config.ini（只改 IpQueryUrl 那一行，注释和其它配置原样保留，
   UTF-8 带 BOM），不用重启、也不用再摸记事本。网址只认 http/https，写错当场拦住。
4. 修复 Win10 缩放自适应：窗口尺寸和最小尺寸现在会按当前显示器工作区兜底收紧，

   取 DPI 也加了三级兜底（GetDpiForWindow → GetDpiForMonitor → 屏幕 DC），
   并且在窗口真正显示之后再校准一次。
5. 状态栏全机网速：底部新增「↑ 12 KB/s  ↓ 150 KB/s」，统计所有在线网卡
   （不含回环与隧道网卡）的实时收发速率，每秒刷新一次；网卡读不到统计就跳过，
   绝不会因为一块虚拟网卡显示不出数字。
6. 复制（Ctrl+C）与导出 CSV 同步带上「运行时长」列，粘到 Excel 里是 8 列。

v0.9 更新记录
-------------
1. 底层瘦身（体积 -58%）：修掉 const 字符串「双份存储」—— C# 的 const 字符串
   会在 exe 里存两份（元数据常量表 + 用户字符串堆各一份），内嵌赞赏码那段

2. 赞赏码换压缩版：内嵌图从 53KB JPEG 换成 200x202 PNG-8（6114 字节），
   二维码内容一字不差，弹窗里依然清晰可扫。
3. 效果：exe 从 456KB 瘦到 191KB（467,456 → 196,096 字节），继续坚持
   「纯单文件、无依赖、双击就能跑」。
4. 功能零变化：本版只动体积，所有功能、界面、快捷键与 v0.8 完全一致。

v0.7 更新记录
-------------
1. 查询网址可自定义：exe 同目录新增 config.ini（第一次运行自动生成，
   发布包里也带了一份默认的），改 IpQueryUrl 那一行即可换查询站点。
   如需自定义查询网址，可在同级目录的 config.ini 中修改 IpQueryUrl，
   支持 {ip} 占位符（如 https://www.ip.cn/?ip={ip}）。
2. 两种写法都认：写了 {ip} 就把 IP 替换进占位符（大小写不敏感）；
   没写占位符就当成前缀，把 IP 拼在末尾——默认的 ip138 就是这种写法，
   所以老用户什么都不改，行为和 v0.6 完全一致。
3. 离线优先不变：exe 同目录有 qqwry.dat 时仍然本地弹窗解析，压根不打开浏览器，
   config.ini 里的网址对这种情况不生效。
4. 安全阀：IpQueryUrl 只认 http:// 与 https://，写成 file:///、本地 exe 路径、
   带空格的可疑串都会被拒（自动退回内置 ip138，并在状态栏提示一句），
   防止有人改 ini 把「查归属地」变成任意程序启动器。
5. 改完 config.ini 不用重启：下次右键查询自动按新配置走（按文件修改时间判断）。
   文件编码 UTF-8 / UTF-16 / 老记事本 ANSI 都能正确读。

5. 归属地数据的准确度取决于库本身：库的内置时间戳在最后一条记录里
   （如「纯真网络 2024年09月25日IP数据」）。官方 dat 格式 2024 年 10 月起停止更新，
   社区镜像仍在维护，想要最新就重跑一次下载脚本。

v0.5 更新记录
-------------
1. 新增「进程类型」列：自动给每个进程打标签——微软核心 / 第三方大厂 / 已签名 /
   未知可疑 / 受保护。识别依据 = 内置特征库 + exe 数字签名，全程离线，

   PID 0/4（内核）会提示定位不了；权限不足读不到路径时也会给出明确提示。
4. 右键「联网搜索此进程」：一键用系统浏览器搜索「Windows进程 xxx 是什么安全吗」。
   这是主动点击后才联网的动作，工具本体依然零联网。
5. 「进程类型」列可点表头排序，按可信度分组：微软核心 → 第三方大厂 → 已签名 →

   也不签名。拿不准就右键联网搜索，或看它的路径再判断。

一、这是什么
一个纯本地的 Windows 网络连接查看器（图形化增强版 netstat -ano），
帮你一眼看出：谁在偷偷联网、哪个端口被占用、后台有没有流氓软件在发包。
单文件绿色软件，解压即用，不写注册表、不联网、不需要管理员权限（普通权限即可运行）。

二、界面说明
[搜索框]  实时过滤，支持：
          - 进程名：chrome
          - 端口号：443（含 8443 这类子串匹配）
          - 地址：192.168
          - 状态：listening / established
          - 进程号：pid:1234（精确匹配 PID）
          - 多个关键词用空格分隔，之间是 AND 关系：tcpv6 443
[刷新]    点一下瞬间重读系统连接表（约 5ms），刷新后列表保持无选中的干净状态，排序不变
[表格]    协议(TCP/TCPv6/UDP/UDPv6)、本地地址:端口、远程地址:端口、状态、PID、进程名、
          运行时长（占用该连接的进程跑了多久，读不到显示 -）、进程类型
          - 点表头排序，再点一次反向；端口按数值、进程名按中文拼音
          - 状态列着色：LISTENING 绿色 / ESTABLISHED 白色 / SYN_* 黄色 / 其余灰色
[顶部]    搜索 / 刷新 / 导出（CSV 快照）/ 自动刷新频率（1/3/5 秒，常开）/ ⚙ 设置
[右键]    复制所选（Tab 分隔，可直接粘进 Excel）、打开进程所在位置、联网搜索此进程、
          查询远程 IP 归属地（有 qqwry.dat 时本地弹窗，否则浏览器按 config.ini 的
          IpQueryUrl 查询）、结束进程、刷新；
          悬停进程名看中文说明
[状态栏]  总条数、TCP/UDP 分布、进程数、刷新耗时、系统版本、当前权限、
          全机网速（↑ 上传 / ↓ 下载，每秒刷新）、已运行 HH:mm:ss

三、结束进程
1. 弹窗二次确认，确认后进程被强制结束；动手前还会按真实进程名再核一次，防止 PID 复用误杀。
2. 内核进程（System/Idle，PID 0~4）和 Windows 关键进程
   （csrss、wininit、services、lsass、smss、winlogon、svchost、dwm、Registry、
   MemCompression 等）会被直接拦截，不允许结束。
3. 其他账户的进程普通权限结束不了，会提示拒绝访问；
   需要时右键 NetEye.exe →「以管理员身份运行」。

四、兼容性
- 清单显式声明支持 Windows 7/8/8.1/10/11，PerMonitorV2 高 DPI：
  4K 屏、多屏不同缩放比例下界面按显示器实际 DPI 矢量缩放，不模糊不裁切。
- Win10 缩放自适应（v0.9.2 修复）：100%/125%/150%/200% 下窗口都会落在屏幕工作区内，
  最小尺寸也不会超过屏幕，拖得小、拉得大；小屏笔记本（1366x768）同样适用。
- 需要 .NET Framework 4.x（Win10/11 系统自带）。
- 读不到名字的进程统一显示 [系统/受保护进程]，绝不因此崩溃或卡死。

五、快捷键

六、自定义查询网址（config.ini）
1. 两种改法，任选其一：
   - 点顶部「⚙ 设置」→ 改网址 → 保存（推荐，程序会替你写好文件）；
   - 或者记事本直接改 exe 同目录的 config.ini，改完保存即生效（无需重启）：
       IpQueryUrl=https://www.ip138.com/iplookup.asp?ip=
2. 原文件长这样（注释可以留着，程序保存时只动 IpQueryUrl 那一行）：
       IpQueryUrl=https://www.ip138.com/iplookup.asp?ip=
3. 两种写法：
   - 前缀式（默认）：目标 IP 自动拼在网址末尾，适合 ...?ip= 这种；
   - 占位符式：网址里写 {ip}，查询时替换成目标 IP，
     例如 IpQueryUrl=https://www.ip.cn/?ip={ip}
4. 只支持 http:// 与 https:// 开头的网址；写错会自动退回内置 ip138，
   状态栏会提示「config.ini 的 IpQueryUrl 无效」，⚙ 设置里也会当场拦住不让保存。
5. 文件被删了也没关系：下次启动自动重新生成一份默认的。
6. 有 qqwry.dat 时优先本地离线解析，不打开浏览器，此配置不生效。

七、隐私
本工具只读取本机系统的 TCP/UDP 连接表，工具本体不联网、不上传任何数据，
进程识别用的数字签名也是读本机 exe 文件、纯离线完成。
会联网的动作（都需要你主动点击）：
1) 「查询远程 IP 归属地」——exe 同目录放了 qqwry.dat 时纯离线弹窗、不联网；
   没放时用系统浏览器打开 config.ini 里配置的查询网址（默认 ip138）查那一行连接的远程 IP；
2) 「联网搜索此进程」——用系统浏览器搜索进程名。
自动刷新、导出 CSV、进程签名识别、全机网速统计全部离线完成。
